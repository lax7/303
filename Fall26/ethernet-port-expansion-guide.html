Hardware Help · Cisco 4331 Router

Adding a Third Working Ethernet Port

Only two of the router's Ethernet ports are active out of the box. If your topology needs a third port, you'll add a GLC-TE module into one of the open NIM (Network Interface Module) slots.

!

The problem: The built-in ports GE0/0/0 and GE0/0/1 work fine, but the router needs a third Ethernet port and there isn't a free onboard port left to use.

1. Current port status

This is the router's Physical Device View. The two onboard ports are highlighted — these are the only two that are currently wired and working.

GE0/0/0

Working — onboard copper Ethernet port

GE0/0/1

Working — onboard copper Ethernet port

3rd port

Not available yet — needs a module installed in an open NIM slot

2. The fix: install a GLC-TE module

From the module list on the left, drag/snap a GLC-TE module into one of the two remaining open slots next to the working ports. This gives the router the extra Ethernet interface you need.

3. Steps to follow

  1. 1

    Power down the module bay (if required by your platform)

    Some physical/simulated chassis require the device or slot to be powered off before a module can be inserted.

  2. 2

    Select GLC-TE from the MODULES list

    It's listed on the left-hand panel along with NIM-2T, NIM-Cover, NIM-ES2-4, GLC-GE-100FX, GLC-LH-SMD, and GLC-T.

  3. 3

    Drag it into one of the two open slots

    Snap it into either of the two empty bays next to the existing GE0/0/0 / GE0/0/1 ports (shown in Fig. 2).

  4. 4

    Confirm the new interface appears

    Check the Physical view (or run show ip interface brief on the CLI tab) to confirm the new Ethernet interface is recognized.

  5. 5

    Bring the interface up and configure it

    Assign an IP address and run no shutdown on the new interface so it's ready to use as your third port.
