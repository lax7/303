Alice, Bob & Eve

Alice sends a message to Bob over a public channel. Eve (a powerful adversary) can copy, delete or modify what travels. Cryptography enforces CIA‑N: Confidentiality (encryption), Integrity (hashing), Availability (redundancy), Non‑repudiation (digital signatures). Kerckhoffs’s principle: the algorithm is public — only the key is secret.

Shift (Caesar) cipher

Map A–Z to 0–25. Enc: C = (m + k) mod 26. Dec: m = (C − k) mod 26. Shift 3 is Caesar’s cipher; shift 13 is ROT‑13. Attack: only 26 keys, so brute force breaks it instantly.

Key length & key space

An n‑bit key gives 2ⁿ keys. Brute force is always possible in principle, so the sufficient key space principle demands a space so large (2¹²⁸+, 256 for quantum worries) that trying all keys takes decades. But a big key space is necessary, not sufficient.

Mono‑alphabetic substitution

The key is a random permutation of the alphabet: 26! ≈ 2⁸⁸ keys — brute force is hopeless. But the cipher preserves letter frequencies: E, T, A, O are common in English, so peaks in the ciphertext give the key away.

Vigenère (poly‑alphabetic) cipher

The key word is repeated; each plaintext letter is shifted by the matching key letter (A=0 … Z=25). One ciphertext letter can stand for many plaintext letters, so frequencies flatten. Attack: find the key length (Kasiski: gcd of distances between repeats; or Index of Coincidence), then do frequency analysis on each column.
